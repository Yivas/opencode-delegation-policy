# Code of Conduct

Discuss the work respectfully. Critique an idea or change without attacking the person behind it.
Give useful context, accept corrections, and keep disagreement relevant to the project.

Harassment, threats, discriminatory abuse, sexual remarks, repeated unwanted contact, and publishing
someone else's private information are not acceptable. Do not post credentials or private
conversations as part of a disagreement.

These rules apply to this repository's issues, pull requests and other project spaces, and to
public representation of the project. The maintainer may edit or remove content, lock a discussion,
warn participants, or restrict participation according to the severity and repetition of conduct.

Report public abuse with GitHub's Report content control on the relevant comment or profile.
That is GitHub's moderation channel, not a confidential inbox operated by this project. For a
private maintainer discussion, request a private contact in an issue without including sensitive
details. Security or data-exposure findings follow [SECURITY.md](SECURITY.md). No response deadline
or confidentiality beyond the chosen channel's capabilities is promised.
